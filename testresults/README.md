# Evidence index

New raw runs stay ignored under <version>/runs/<run>/; inspect actual outcomes and
archive using [the evidence policy](../docs/EVIDENCE.md). Git contains only compact
summaries/descriptors/reports outside runs. No historical execution proves current
product behavior. Template publication evidence is separate from generated projects.

[Initial template validation](0.1.0/template-bootstrap/summary.md) records pre-publication
scope and local archive access. Generated projects must create their own evidence.
